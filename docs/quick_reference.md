## 📊 客户状态参考

### 状态流程
```
潜在客户 (Prospect)
    ↓
合格客户 (Qualified)
    ↓
新客户 (New Customer)
    ↓
活跃客户 (Active Customer)
    ↓
非活跃客户 (Inactive Customer)

分支状态：
- 不合格客户 (Not Qualified)
- 失去客户 (Lost Customer)
- 已关闭失败 (Closed Lost)
- 已关闭成功 (Closed Won)
```

### 状态颜色代码
| 状态 | 颜色 | 描述 |
|------|------|------|
| 潜在客户 | 蓝色 | 初步接触 |
| 合格客户 | 绿色 | 通过初步筛选 |
| 新客户 | 紫色 | 新签约客户 |
| 活跃客户 | 深绿 | 持续合作 |
| 非活跃客户 | 橙色 | 需要激活 |
| 不合格客户 | 红色 | 不符合标准 |

## 📈 数据导出指南

### 导出格式
- **CSV格式**: 兼容Excel
- **自定义字段**: 选择需要的列
- **日期范围**: 指定时间段
- **筛选条件**: 应用当前筛选

### 导出步骤
1. 设置筛选条件
2. 点击"导出"按钮
3. 选择导出字段
4. 确认并下载

## 🛠️ 故障排除

### 常见问题速查
| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 无法登录 | 密码错误 | 重置密码或联系管理员 |
| 页面加载慢 | 网络问题 | 刷新页面或检查网络 |
| 数据不显示 | 权限不足 | 联系管理员检查权限 |
| 导出失败 | 数据量过大 | 缩小日期范围 |
| 邮件发送失败 | SMTP配置错误 | 检查邮件设置 |

## 🔐 安全提醒

### 密码安全
- 使用强密码（8位以上，包含数字和字母）
- 定期更换密码
- 不要与他人分享账号

### 数据保护
- 定期备份重要数据
- 不要在公共设备上保存登录信息
- 及时退出系统

### 权限管理
- 按需申请权限
- 离职时及时删除账号
- 定期审查权限设置
