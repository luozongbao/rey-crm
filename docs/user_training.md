## 🎯 第一部分：系统概述与登录

### 1.1 系统介绍
Rey CRM System 2.0 是一个现代化的客户关系管理系统，具有以下特点：
- **多语言支持**：中文/英文界面
- **响应式设计**：支持桌面和移动设备
- **企业级功能**：权限管理、数据安全
- **智能化**：自动化工作流程

### 1.2 首次登录
1. 打开浏览器，访问系统地址
2. 输入用户名和密码
3. 首次登录后建议：
   - 修改默认密码
   - 设置个人资料
   - 选择界面语言

### 1.3 界面布局
- **顶部导航栏**：主要功能模块入口
- **侧边栏**：快速导航和功能菜单
- **主内容区**：工作区域
- **状态栏**：系统信息和通知

## 🏢 第二部分：客户管理

### 2.1 客户列表查看
**导航路径**：仪表板 → 客户管理 → 所有客户

**操作演示**：
1. 点击"客户管理"菜单
2. 查看客户列表，包含：
   - 公司名称
   - 联系信息
   - 状态标识
   - 最后联系时间
   - 分配用户

### 2.2 添加新客户
**步骤演示**：
1. 点击"添加客户"按钮
2. 填写客户基本信息：
   ```
   必填字段：
   - 公司名称
   - 联系电话
   - 公司状态
   
   可选字段：
   - 地址信息
   - 邮箱
   - 网站
   - 备注
   ```
3. 选择客户状态：
   - 潜在客户
   - 合格客户
   - 新客户
   - 活跃客户
   - 非活跃客户

### 2.3 客户信息编辑
**实践操作**：
1. 在客户列表中找到目标客户
2. 点击"编辑"按钮
3. 修改相关信息
4. 保存更改

### 2.4 客户状态管理
**状态流程图**：
```
潜在客户 → 合格客户 → 新客户 → 活跃客户
    ↓           ↓         ↓         ↓
不合格客户    失去客户   非活跃客户  已关闭
```

**最佳实践**：
- 定期更新客户状态
- 根据业务流程调整状态
- 使用备注记录状态变更原因

## 👥 第三部分：联系人管理

### 3.1 联系人概述
每个客户可以有多个联系人：
- **主要联系人**：自动创建，受保护
- **次要联系人**：可自由添加/删除

### 3.2 添加联系人
**操作流程**：
1. 进入客户详情页面
2. 在联系人区域点击"添加联系人"
3. 填写联系人信息：
   - 姓名（必填）
   - 职位
   - 角色
   - 电话
   - 邮箱
   - 备注

### 3.3 联系人管理技巧
**演示要点**：
- 主要联系人无法删除（系统保护）
- 角色信息显示在列表中
- 联系人历史记录跟踪
- 批量操作支持

## 📊 第四部分：活动历史与跟进
